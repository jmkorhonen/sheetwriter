Name

SheetWriter

Open online Source repository Readme (direct link)

A text editor whose document is an Excel workbook. One argument per row, extra columns for notes, sources, examples. Each sheet is a chapter. The kind column marks headings and paragraphs, indent nests rows, no holds the numbering, written on save. Cells are Markdown.

Kinds and structure

h1 … h4Headings. h1 is always one number (1, 2, 3), h2 two (2.1), h3 three (2.1.1). Numbering continues from sheet to sheet, so a chapter per sheet that starts with an h1 row is numbered 2, 3, …; Settings can make each sheet restart at 1 instead. Type # to #### and a space at the start of a row to set the kind.
pParagraph. Numbered one level below its heading, plus its indent.
indentTab / Shift+Tab (Draft view), Ctrl+] / Ctrl+[, or type three spaces at the start of a row (changeable in Settings). An indented row under 2.1 becomes 2.1.1.
sSentence that continues the previous paragraph on export (still its own row and number).
xExcluded from export (a parked argument, a note to self).

Selecting rows

Click number or ⋮⋮Select the row. Shift+click selects a range, Ctrl+click adds or removes a row. A collapsed heading brings its hidden rows.
Ctrl+Shift+↑ / ↓Extend the selection from the row being edited.
Ctrl+ASelect all rows (when no text field is focused).
Ctrl+C / X / V / D, DeleteCopy, cut, paste, duplicate, delete the selected rows (when no text field is focused; the bar at the bottom has the same buttons). Pasting keeps every column, also into other sheets, and adds missing columns.
EscClear the selection.
Drag a selected ⋮⋮Move all selected rows, also onto another sheet's tab.

Markdown import

Markdown ▾ → Import, or drop a .md file on the window. One paragraph per row by default; files written one sentence per line are detected and imported line by line; a sentence mode splits paragraphs into p and s rows. Lists become indented rows, and the side-column blockquotes and comments that Export writes are read back into their columns, so export and import round-trip. Import into a new sheet, one sheet per h1, or the current sheet. Several files at once become several sheets.

Table of contents

The Contents button opens a pane listing the headings of this sheet or of all sheets, with numbers and section word counts. Click a heading to jump to it in Draft, Grid or Read view; collapsed sections open on the way. The heading you are working under is highlighted.

Grid, columns and tabs

Columns are shared by all chapter sheets: adding, renaming, deleting or reordering a column applies everywhere, and deleting warns if any sheet holds data in it. Click a column name to rename it, drag a column header to reorder, drag its right edge to resize. The – button hides a column in Grid view; the Columns ▾ button chooses which columns the Grid and Draft views show. Rows hide in Grid by collapsing (▾ in the number cell, Collapse all) or by typing in the filter box above the table. Double-click a sheet tab to rename it. Drag rows by the ⋮⋮ handle, drag tabs to reorder chapters. Click the title in the toolbar to change it.

Files

In Edge and Chrome the app opens and saves the .xlsx in place and keeps a Recent list. In Firefox and Safari, Open uses a file picker and Save downloads a copy. Unsaved work is also kept in the browser and offered back on the next start. Sheets without a main text column are data sheets: shown read-only, written back unchanged. A workbook edited or sorted in Excel is put back in no order on load; rows without a number go last. A plain spreadsheet without a text column is imported using its longest text column.
